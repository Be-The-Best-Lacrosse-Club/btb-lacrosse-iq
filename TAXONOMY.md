# BTB Lacrosse IQ — Complete Concept Taxonomy

Designed for Dan Achatz and BTB Lacrosse Club coaches to find any play moment in seconds.
Structure: Category > Sub-concept > Specific Action > Variation

---

## How to Use This Taxonomy

Search is additive — type any word at any level of the tree and all matching clips appear.
The search engine expands synonyms automatically (see SEARCH_SYNONYMS in taxonomy.js).

Example query path:
  "two-man game throwback backpipe feed finish"
  -> Category: TWO_MAN_GAME
  -> Sub-concept: THROWBACK_PASS
  -> Action: BACKPIPE_THROWBACK_FEED
  -> Variation: (crease finish, near pipe, far pipe)

## Appendix B: Difficulty Levels

### Beginner
- Single-concept, slow tempo, stationary or slow-moving ball
- Dodge without defensive pressure
- Feed from set position
- Basic save technique
- Basic faceoff clamp

### Intermediate
- Two-concept sequence (dodge + feed, pick + roll)
- Moderate defensive pressure
- Transition reads (2v1, 3v2)
- EMO rotation with one pass
- Faceoff with outlet

### Advanced
- Three+ concept chain (dodge + feed + off-ball cut + finish)
- High defensive pressure
- Fast break with trail man
- EMO crash backpipe
- Man-down slide rotation
- X play with back-door cutter

### Elite
- Full multi-concept sequences under game pressure
- Throwback + backpipe feed + crease finish under pressure
- Man-down stops on backpipe EMO
- Faceoff to immediate fast break finish
- Goalie drive-from-X under pressure
